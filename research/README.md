# Research Documentation

## Purpose
This directory contains structured research materials, evidence appraisal tools, and disease-specific documentation. All material claims must be traceable and conservative per `AGENTS.md`.

## Workflow
1. **Register sources** in `source-register.csv` before or when citing them as factual.
2. **Appraise studies** using `../templates/study-appraisal.md`.
3. **Track claims** in `claim-ledger.csv` with evidence level, supporting/conflicting sources, limitations, confidence.
4. **Document by disease** under `diseases/<disease-name>/`.
5. **Follow methodology** in `evidence-methodology.md` for appraisal, certainty, and updates.

## Source Management
- Prefer primary sources (original publications, registries).
- Record DOI/registry ID, URL, source type, population, status, `last-verified` date.
- Mark unverifiable claims explicitly.
- Keep publication dates to assess staleness.

## Disease Directories
- `diseases/type-2-diabetes/` — T2D biology, remission evidence, mechanisms, interventions, trials, gaps.
