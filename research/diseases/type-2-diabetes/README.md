# Type 2 Diabetes — Research Directory

## Overview
This directory documents evidence on Type 2 diabetes pathophysiology, remission, mechanisms, interventions, trials, and research gaps. All content must follow `../../../AGENTS.md` and `../../evidence-methodology.md`.

## Files
- `disease-biology.md` — Pathophysiology, fat distribution, insulin resistance, beta-cell dysfunction
- `remission-evidence.md` — Definitions, DiRECT, DIADEM-I, systematic reviews, durability/relapse
- `beta-cell-recovery.md` — Evidence for recovery vs compensation; preclinical/human separation
- `emerging-treatments.md` — Pharmacologic, surgery, regenerative approaches
- `natural-compounds.md` — Shikuwasa, nobiletin, tangeretin, amla, jamun, mosambi, kinnow (evidence by type)
- `clinical-trials.md` — Registry-tracked trials with verification protocol
- `research-gaps.md` — Gaps and conservative prioritization framework

## Principles
- Distinguish remission, control, modification, cure
- Separate on-treatment from medication-free/remission outcomes
- Report nulls and contradictions
- No treatment recommendations
- Trace claims to sources or flag unverified
- Never promise cures
